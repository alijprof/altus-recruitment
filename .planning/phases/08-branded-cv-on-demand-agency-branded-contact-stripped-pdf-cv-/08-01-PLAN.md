## Storage-model decisions this plan locks in

- **New table, not a flagged `candidate_cvs` row** (research §Storage
  Modelling Options): overloading `candidate_cvs` would force two constraint
  changes plus `kind`-aware branching in `cv-files-panel.tsx`, `nextCVVersion()`
  and the frozen Phase-6 smoke suite. A new table leaves every tested Phase
  6/7 path untouched.
- **Reuse the existing `cvs` bucket for the branded PDF** — its policy is
  `(storage.foldername(name))[1] = current_organization_id()::text`, which
  imposes nothing on the path below the first segment, so
  `{org}/{candidate}/branded-cv-{uuid}.pdf` needs no new bucket and no new
  policy, and `ORG_STORAGE_BUCKETS` already sweeps it.
- **New PRIVATE `org-logos` bucket for the logo** — logos are org-scoped, not
  candidate-scoped; a dedicated bucket keeps the `{org}/{candidate}/...`
  convention of `cvs` uniform. Private, because every bucket in this project
  is private by deliberate policy (Storage RLS does not apply to public
  buckets — see the header comment on `20260517204501_storage_cvs_bucket.sql`).

Existing conventions the new table MUST mirror (from
`supabase/migrations/20260513152244_phase1_domain_schema.sql`, the
`candidate_cvs` block at lines ~477-486):

```sql
-- Tenant policy quad shape used by every domain table
create policy "Tenant select own org <thing>" on public.<t> for select to authenticated
  using (organization_id = public.current_organization_id());
create policy "Tenant insert own org <thing>" on public.<t> for insert to authenticated
  with check (organization_id = public.current_organization_id());
create policy "Tenant update own org <thing>" on public.<t> for update to authenticated
  using (organization_id = public.current_organization_id())
  with check (organization_id = public.current_organization_id());
create policy "Tenant delete own org <thing>" on public.<t> for delete to authenticated
  using (organization_id = public.current_organization_id());

-- Trigger pair present on every tenant table
create trigger <t>_set_org before insert on public.<t>
  for each row execute function public.set_organization_id();
create trigger <t>_set_updated_at before update on public.<t>
  for each row execute function public.set_updated_at();
```

Storage bucket + policy shape (from `20260517204501_storage_cvs_bucket.sql`):

```sql
insert into storage.buckets (id, name, public, file_size_limit, allowed_mime_types)
values ('<bucket>', '<bucket>', false, <bytes>, array[...]) on conflict (id) do nothing;

create policy "Tenant select own org <bucket>" on storage.objects for select to authenticated
  using (bucket_id = '<bucket>'
         and (storage.foldername(name))[1] = public.current_organization_id()::text);
-- ...and the matching insert (with check) / update (using + with check) / delete (using)
```
