## Non-negotiable architecture (production incident, 2026-08-11)

The View control MUST be a plain `<a>` to a route handler. The Phase-7 original
opened a blank popup and awaited a Server Action inside `startTransition`: on
production the action returned 200 with a valid signed URL and the client
promise NEVER SETTLED — no branch ran, no toast, no error, the popup orphaned at
`about:blank`, and seven jsdom tests passed the whole time. Do not reintroduce
any client-side promise into this gesture path. Read `07-HOTFIX.md` §4 before
writing a line of this plan.

The audit row is stronger under this architecture and the reason is worth
keeping: with a redirect, release and delivery are the SAME HTTP response, so a
row can no longer be filed for a document the recruiter never received.
</objective>

- ONE path segment to shape-gate (`id`), because the table is keyed 1:1 on
  `candidate_id` — the URL is `/candidates/[id]/branded-cv`, no second id.
- The row lookup is by `candidate_id`, so the "candidate id in the path must be
  the row's own" check is structurally unnecessary; drop it.
- No `isCvFileDownloadable` equivalent — a row only exists if a PDF was stored.
  A `getBrandedCvState` of `unavailable`/`none` collapses into the same 404.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| unauthenticated/any-tenant browser → `/candidates/[id]/branded-cv` | A guessable URL addresses a PII document |
| route handler → Supabase Storage signing | A short-lived credential is minted and handed to a browser |
| erasure request → Storage + Postgres | A compliance obligation to destroy data completely |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
